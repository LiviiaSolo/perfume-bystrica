# 🌸 Perfume Bystrica — Elegant landing page for a perfume manufacturer.

Clean, elegant and fully responsive landing page for a perfume manufacturer in Banská Bystrica.
Designed to showcase fragrances, highlight product categories and ensure a smooth shopping process.


## ✨ Features

- Fully responsive design (mobile, tablet, desktop)

- Elegant UI with soft transitions

- Product cards with images and descriptions

- Category sections for easy navigation

- Contact & location information

- Optimized layout for fast loading


## 🛠 Tech Stack

- HTML5

- CSS3

- JavaScript

- Flexbox / Grid

- GitHub Pages (deployment)


## 👩‍💻 My Role

- Concept & UI Design — complete creation of the website structure, visual style, color palette and layout without using Figma.

- Layout development — building all sections based on my own design with a clear and logical structure.

- Responsive design — adapting the website for mobile, tablet and large screens.

- Animations — adding smooth transitions to create a refined and pleasant browsing experience.

- Image optimization — preparing and compressing product photos for fast loading.

- UI adjustments — small design refinements to improve readability and visual harmony.

- Deployment preparation — preparing the project for hosting on Netlify and GitHub Pages.
